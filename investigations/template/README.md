# Investigation Template

Copy this directory to `investigations/<investigation-id>/` for every future investigation. The subdirectories preserve a deterministic lifecycle from preregistration through retained evidence, results, figures, and artifacts.

## Required Items

- `investigation-design.md`: bounded investigation design and status statement.
- `preregistration.md`: frozen protocol registration and scope definition placeholder.
- `literature/`: literature-review notes and source traceability.
- `bor/`: baseline observation records.
- `srf/`: surface record files.
- `der/`: derived evidence records.
- `msr/`: measurement summary records.
- `dataset/`: investigation-local datasets.
- `analysis/`: analysis notebooks, scripts, or reports.
- `results/`: investigation results and deterministic outputs.
- `figures/`: investigation-specific figures.
- `artifacts/`: publication and release artifacts.
