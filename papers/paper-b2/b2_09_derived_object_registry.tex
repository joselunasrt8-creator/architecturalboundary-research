\section{Derived Object Registry}
\label{sec:der}
This section completes the manuscript DER for the B2 governance cohort by registering derived objects
\emph{only} when they can be traced to documented Source Reference Files (SRFs).

\textbf{Separation rule.} DER entries are derivations only: no new observations, measurements, classifications, hypotheses, or conclusions may be introduced here. Every object must include an explicit trace pointer to SRF observations.
