# Scripts

Deterministic helper scripts for validating, building, publishing, and regenerating repository registries.

`validate_architectural_investigation_instrument.py` validates only the
mechanical identities, hashes, readiness coherence, gap inventories,
calibration-fixture structure, lineage, Issue #108 containing-commit binding,
and preserved blocked-execution boundary of Instrument v1 candidates 1 and 2.
It does not classify evidence, perform an independent calibration review,
adjudicate disagreements, or make scientific judgments.
