\subsubsection{Cohort-wide summary (metric extract)}
Using the Comparative Dataset metric extract (Section~\ref{sec:comparative-dataset}), the cohort exhibits the following patterns across the nine candidate objects (DER-001--DER-009):
\begin{itemize}
  \item \textbf{Decision component present (MET-001):} 9/9 candidates.
  \item \textbf{Execution component present (MET-002):} 4/9 candidates (DER-002, DER-006, DER-007, DER-008).
  \item \textbf{Policy enforcement/policy evaluation surface present (MET-003):} 9/9 candidates.
  \item \textbf{Decision and execution separated (MET-004):} 2/9 candidates (DER-002, DER-007).
  \item \textbf{Authorization before execution (MET-005):} 1/9 candidates (DER-002); DER-007 explicitly records non-evidence for this ordering (MET-005=0).
  \item \textbf{Execution surface explicitly documented (MET-006):} 9/9 candidates.
  \item \textbf{Policy evaluation surface explicitly documented (MET-007):} 8/9 candidates; Cedar/AVP (DER-009) is the sole candidate with MET-007=0.
  \item \textbf{Audit/decision-trace surface present (MET-008):} 1/9 candidates (DER-003).
\end{itemize}
