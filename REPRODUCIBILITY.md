# Reproducibility

This repository is designed so each investigation can be replayed from protocol registration through retained classification.

## Deterministic Replay Expectations

- Registrations are frozen before evidence collection.
- Evidence artifacts remain traceable to their source investigation.
- Datasets distinguish canonical, comparative, and published states.
- Scripts are deterministic and should not introduce hidden execution paths.
- Publication artifacts should be derivable from registered evidence, datasets, and analysis outputs.
