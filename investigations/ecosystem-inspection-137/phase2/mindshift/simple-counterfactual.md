# MindShift simple evidence/claim checklist

This record is the prospectively frozen simpler counterfactual for Issue #137.

It intentionally uses no ABR-specific machinery.

For each material target artifact, inspect only:

1. exact artifact and revision identity;
2. claim;
3. evidence supporting the claim;
4. assumptions;
5. unresolved uncertainty;
6. current status;
7. authority / non-authority boundary;
8. blocker or stopping condition.

## Output rule

Record only information directly supported by the pinned MindShift artifacts.

Do not:

- formulate new research hypotheses;
- introduce ABR terminology;
- infer missing evidence;
- reinterpret blocked or invalid results as outcomes;
- promote candidate cognition into findings;
- treat documentation as execution evidence.

## Comparison purpose

The checklist is sufficient if it identifies the same decision-relevant gaps and boundaries as ABR with equal or lower burden.

ABR demonstrates unique incremental value only if it identifies a decision-relevant question, rival explanation, evidence requirement, or boundary that:

1. is absent from MindShift's native baseline;
2. is absent from this simple checklist;
3. is supported by the frozen repository evidence; and
4. can plausibly change, stop, narrow, or clarify a research decision.
