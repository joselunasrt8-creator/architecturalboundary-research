# Literature and Novelty Review

**Status:** documentation-only review completed before preregistration, experiment execution, evidence collection, empirical interpretation, or any novelty claim.

This directory evaluates the relation of the prospective context-scaling-versus-explicit-abstraction investigation to selected **primary** research. It does not report an experiment, observations, source/target tasks, or an empirical outcome. The candidate hypothesis remains a candidate hypothesis.

## Review artifacts

1. [Review protocol](literature-review-protocol.md) defines the question, search boundary, inclusion decisions, and limitations.
2. [Source registry](source-registry.md) identifies the primary sources reviewed and their canonical locations.
3. [Evidence summaries](evidence-summaries.md) records source-bounded findings without treating secondary commentary as evidence.
4. [Comparison matrix](comparison-matrix.md) compares adjacent methods with the proposed prospective conditions.
5. [Terminology reconciliation](terminology-reconciliation.md) maps repository terms to established, qualified terms.
6. [Design implications](design-implications.md) records changes that must be addressed before preregistration; it does not alter the design.
7. [Novelty determination](novelty-determination.md) gives the sole bounded determination.

The review is limited to the registered protocol and the sources in the registry. It cannot establish universal priority or prove that no comparable work exists.
