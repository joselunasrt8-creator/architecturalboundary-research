\section{Measurement Registry}
\label{sec:msr}
The measurement registry (MSR) records protocol-defined measurements computed over derived objects. The current repository state contains complete canonical MSR executions for all nine B2 cohort systems and a complete canonical Comparative Dataset projection. Analysis and Retained Classification remain not started.

\textbf{Separation rule.} MSR entries must not introduce new observations. Each measurement must cite its DER inputs (and thereby inherits BOR traceability). Any aggregation or normalization performed for a measurement must be described as part of the measurement method.

\textbf{MSR schema.} Canonical executions use machine-readable schema \texttt{schemas/msr.schema.json} with schema version \texttt{canonical-msr-v1}.

\textbf{Measurement boundary.} The MSR layer uses only the registered I4 measurement vector: \texttt{m\_R}, \texttt{m\_L}, \texttt{m\_E}, \texttt{m\_RL}, and \texttt{m\_LE}, each with \texttt{boolean\_or\_missing} semantics. These records do not state cohort conclusions, architectural invariants, or retained classifications.
