\section{Derived Object Registry}
\label{sec:der}
The derived object registry (DER) records protocol-defined objects extracted from the baseline observations. DER entries are interpretive: they normalize heterogeneous evidence into a common set of object types (e.g., policy entity, principal, resource, evaluation component, enforcement hook, and execution surface).

\textbf{Separation rule.} Each DER entry must cite its supporting BOR IDs and evidence pointers. No new observations may be introduced in DER; only derivations from previously recorded BOR facts are allowed.
