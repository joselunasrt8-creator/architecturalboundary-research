# Repository-Owned Instruments

This directory contains versioned, repository-owned instrument surfaces. An
instrument directory is not executable authority merely because it exists.
Every instrument version must have a deterministic manifest and a separate
repository-owned readiness determination before an audit may bind it.

The historical [Architectural Investigation Instrument v1 candidate.1](architectural-investigation/v1/README.md)
is preserved. Issue #107's [candidate.2 readiness overlay](architectural-investigation/v1/candidate-2/README.md)
resolves the general semantic gaps. The [Issue #108 readiness adjudication](../docs/reference-execution/v1.0/architectural-investigation-instrument-v1-readiness-adjudication-issue-108.md)
binds its exact containing commit but preserves unavailable qualified independent
calibration and exemplar-review evidence. Candidate.2 remains unfrozen with
determination `INSTRUMENT_SPECIFICATION_REVISION_REQUIRED`.
