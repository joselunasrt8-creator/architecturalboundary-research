\section{Baseline Observation Records}
\label{sec:bor}
This section records Protocol v1.0 baseline observations for each system prior to any boundary evaluation.

\textbf{Separation rule.} BOR entries are factual statements only (``what is described/implemented''), each paired with an evidence pointer. All interpretation (e.g., mapping an interface to an ``execution surface'') must be recorded later in the DER/MSR and referenced via trace pointers.

\textbf{BOR completion status.} The machine-readable repository contains complete canonical BOR artifacts for all nine B2 cohort systems. This manuscript table records their canonical identifiers and artifact pointers without restating or reinterpreting the underlying observations.
