# B2 Governance Cohort DER Records

This directory contains Derived Evidence Records (DER) for the B2 governance cohort when DER execution is intentionally performed.

## Canonical Reference DERs

- `openfga.der.json` is the Canonical Reference DER for the OpenFGA authorization-model lifecycle execution surface.
- `envoy-ext-authz.der.json` is the Canonical Reference DER for the Envoy ext_authz external authorization delegation execution surface.

These records serve as reference executions of the frozen SRF→DER contract. Remaining DER records will be produced separately.

This directory does not indicate that B2 DER execution is complete.
