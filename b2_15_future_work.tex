\section{Future Work}
\label{sec:future-work}
Future work is restricted to execution and maturation activities that preserve the separation between empirical evidence (Program~B) and formal proof (Program~A). No new architectural theories are introduced.

\subsection{Next research question: boundary emergence conditions}
B2 establishes that the complete explicit Reasoning$\rightarrow$Legitimacy$\rightarrow$Execution boundary (under the strict preregistered I5 definition) is not cohort-wide. The next investigation should explain variation:
\begin{quote}
Under what conditions does a complete Reasoning $\rightarrow$ Legitimacy $\rightarrow$ Execution boundary emerge?
\end{quote}

\subsection{Expand the cohort}
\begin{itemize}
  \item Add additional governance/authorization systems to broaden representational diversity while keeping Protocol v1.0 frozen.
  \item Evaluate multiple versions of existing cohort systems to test temporal robustness under controlled version selection.
\end{itemize}

\subsection{Replication studies}
\begin{itemize}
  \item Perform independent replications of the Paper~B2 execution using the same protocol registration fields and decision rule.
  \item Run inter-analyst replications to assess agreement on BOR extraction and DER normalization choices.
\end{itemize}

\subsection{Independent implementations}
\begin{itemize}
  \item Implement independent extraction/measurement pipelines that target the same BOR/DER/MSR schemas and compare outputs for consistency.
\end{itemize}

\subsection{Candidate promotion to Program~A}
\begin{itemize}
  \item If the candidate boundary remains supported across replications and cohort expansions, nominate B2-BND-001 for Program~A evaluation (formalization and proof attempts), without importing unregistered assumptions from Program~B.
\end{itemize}

\subsection{Protocol refinement}
\begin{itemize}
  \item Propose Protocol v1.0 refinements (as a future protocol version) only after completing replications, and only as changes that improve traceability, reduce degrees of freedom, or clarify measurement definitions.
\end{itemize}
