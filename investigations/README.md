# Investigations

Preregistered executions of the protocol. Each investigation should follow the reusable scaffold in `templates/`.

Repository-audit and instrument-rehearsal records that are not Protocol v1
investigations remain outside the investigation registry. The
[Structural Analysis Foundations audit package](structural-analysis-foundations-audit-1/README.md)
preserves a fail-closed Issue #84 preflight with `BLOCKED` execution validity and
`NOT_REACHED` audit outcome; it is not a completed audit or a registered Protocol
v1 investigation.
