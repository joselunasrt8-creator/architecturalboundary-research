\section{Measurement Registry}
\label{sec:msr}
The measurement registry (MSR) records protocol-defined measurements computed over derived objects. The current repository state contains exactly two canonical MSR reference executions, for OpenFGA and Envoy ext\_authz; cohort-wide MSR execution remains incomplete.

\textbf{Separation rule.} MSR entries must not introduce new observations. Each measurement must cite its DER inputs (and thereby inherits BOR traceability). Any aggregation or normalization performed for a measurement must be described as part of the measurement method.

\textbf{MSR schema.} Reference executions use machine-readable schema \texttt{schemas/msr.schema.json} with schema version \texttt{canonical-msr-v1}.
