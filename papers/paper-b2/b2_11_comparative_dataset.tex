\section{Comparative Dataset}
\label{sec:comparative-dataset}
This section assembles a cohort-level comparative dataset derived from the system-specific registries (BOR/ESM/DER/MSR). The dataset is the cohort-facing view used for analysis and classification; each field must remain traceable to underlying registry entries.

\textbf{Dataset schema.} The canonical machine-readable export uses schema version \texttt{canonical-dataset-v1} at \texttt{schemas/dataset.schema.json} and is generated at \texttt{investigations/b2-governance-cohort/dataset/b2-governance-cohort-i4.dataset.json}.
